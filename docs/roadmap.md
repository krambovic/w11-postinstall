# Дальнейшая разработка

Полный первоначальный замысел — в PLAN.md. Ниже фактическое состояние реализации с учётом запрета скачиваний/установок на машине пользователя.

| Область | 0.2.0-preview | До стабильной версии |
|---|---|---|
| CLI | Один файл для распространения, цветной мастер RU/EN, ручное меню, CLI-параметры | Расширенная локализация ошибок и объяснения действий |
| Планирование | Снимок, хеш, исходный SID, проверка drift | Более строгие схемы журналов, миграции, подпись плана |
| Восстановление | Значения HKCU, intent, конфликты | Выборочный откат, повторная проверка после перезагрузки |
| Debloat | Только точные Appx текущего пользователя | Provisioned-пакеты/другие пользователи после отдельной проверки |
| Tweaks | 15 настроек HKCU | Проверенные системные настройки, питание, автозагрузка, службы/задачи |
| Установки | Choco / WinGet, явные лицензии, нет bootstrap | Проверка всех ID/версий/scope, свободного места, portable/Store, offline cache |
| Программы | 104 кандидата, в том числе 19 ArtCraft | Проверенные автоматические пакеты Crafting Apps, без выдуманных ID |
| Defender | Диагностика; удаление Unsupported | Исследование и VM-валидация remover по каждой сборке |
| Backup | Собственный журнал реестра | Точки восстановления с проверкой результата; интеграция с образами |
| Пользовательский контекст | Привязка к SID, без повышения прав | Разделение user/admin-процессов без подмены HKCU |
| Совместимость | Детектор 21H2–26H2; все Unverified | Матрица реальных испытаний, ARM64 и дополнительные редакции |
| Проверки | Dependency-free offline harness, CI | Pester/PSScriptAnalyzer при наличии ресурсов, изолированные VM |
| Производительность | Нет недоказанных обещаний | Воспроизводимые замеры до/после с медианой и разбросом |
| Отчёты | Локальный JSON, консольная таблица | Markdown, автоматическое обезличивание |

Профили Laptop и Minimal в preview содержат только небольшой доступный набор; полноценная оптимизация питания и системных компонентов пока не реализована. Не называть этот релиз «максимальной оптимизацией всех Windows 11» до проверки эффектов.
