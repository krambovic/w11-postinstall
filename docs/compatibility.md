# Совместимость

Это целевая матрица, **не список уже протестированных систем**.

| Windows 11 | Базовая сборка | Реальные испытания |
|---|---:|---|
| 21H2 | 22000 | Не выполнены |
| 22H2 | 22621 | Не выполнены |
| 23H2 | 22631 | Не выполнены |
| 24H2 | 26100 | Не выполнены |
| 25H2 | 26200 | Не выполнены |
| 26H1 | 28000 | Не выполнены, отдельная платформа |
| 26H2 | 26300 | Не выполнены |

Детектор использует точные сборки, редакцию и архитектуру. Preview Apply: AMD64; Core, CoreSingleLanguage и Professional; 64-битный процесс. Это ограничение доступности непроверенного preview, а не сертификат совместимости. Остальные редакции, ARM64 и неизвестные сборки блокируются. Plan/диагностика доступны при наличии нужных системных командлетов.

Для каждого действия необходимы: применение, идемпотентный повтор, перезагрузка/повторный вход, проверка эффекта в UI и откат на конкретной редакции и сборке. Простая запись ключа и чтение значения доказывают сохранение параметра, но не то, что Windows использует его на данном выпуске. Поэтому все записи каталога пока Unverified.

В этой сессии выполнены только синтаксические и имитационные проверки в уже установленных Windows PowerShell 5.1 и PowerShell 7. Ни VM, ни образы, ни установщики не скачивались. Hosted CI тоже проверяет только логику на имитациях.

Кандидат пакета в Choco/WinGet не гарантирует поддержку старого выпуска Windows последней версией приложения. Перед установкой менеджер должен найти применимый пакет; это не подменяет тестирование конкретного установщика.

Срок поддержки Windows Microsoft и совместимость скрипта — разные вещи. Актуальные сведения о выпусках: [Microsoft release information](https://learn.microsoft.com/en-us/windows/release-health/windows11-release-information).
