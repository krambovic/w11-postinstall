# W11 PostInstall

CLI для настройки Windows 11 после установки: debloating, приватность, интерфейс, выбор программ, **Chocolatey (recommended) / WinGet**, предварительный план и восстановление настроек реестра.

[English](README.md) · [Использование](docs/usage.md) · [Совместимость](docs/compatibility.md) · [Восстановление](docs/recovery.md) · [Следующие этапы](docs/roadmap.md)

## Текущее состояние — 0.1.0-preview

Реализована первая рабочая версия CLI. Проверки выполнены **только на имитациях**: установка программ и изменение Windows на машине разработчика не запускались. Проверка конкретных сборок на VM ещё предстоит.

- Встроенный Windows PowerShell 5.1, без дополнительных модулей и загрузки зависимостей.
- Меню RU/EN; профили Balanced, Minimal, Gaming, Privacy, Laptop и Custom.
- Выбор менеджера: **Chocolatey (recommended)** первым и по умолчанию; WinGet вторым. Это предпочтение проекта, а не доказанное преимущество скорости или безопасности.
- **104 программы**: браузеры, редакторы, общение, утилиты, офис, игры, творчество и AI. Среди современных вариантов: Zen, LocalSend, Flow Launcher, NanaZip, Obsidian, Cursor, LM Studio, Jan, uv.
- **19 позиций ArtCraft**: Studio, Launcher, PhotoCraft, VectorCraft, FilmCraft, LightCraft, PdfCraft, EffectCraft, AniCraft, DesignCraft, FigCraft, TextureCraft, MaterialCraft, SoundCraft, WordCraft, DeckCraft, CADCraft, GridCraft и Craft Anything. Пока доступны официальные ссылки для ручной установки. У многих приложений статус alpha/in development.
- 15 пользовательских твиков реестра и 13 точечных действий удаления Appx для текущего пользователя.
- Проверка целостности плана и исходного состояния; журнал до/после операции; восстановление реестра с обнаружением конфликтов.
- Диагностика Defender. **Удаление Defender пока заблокировано**: проверенного метода нет, флаги подтверждения его не включают.

Все соответствия пакетов в каталоге помечены `candidate`: установка и актуальность каждого пакета ещё не проверены. При отсутствии пакета выбранного менеджера скрипт показывает ручную установку, а не незаметно переключает менеджер.

## Запуск

```powershell
.\Start.ps1
.\Start.ps1 -Mode Catalog
.\Start.ps1 -Mode Plan -Profile Balanced
.\Start.ps1 -Mode Plan -Profile Custom -Provider Choco -Apps firefox,vlc,7zip -OutFile .\plan.json
.\Start.ps1 -Mode Apply -PlanFile .\plan.json -WhatIf
```

`Plan` только читает состояние и при явно заданном `OutFile` сохраняет файл. `Apply -WhatIf` не запускает менеджеры, не создаёт журнал и не меняет Windows. `Start.cmd` запускает PowerShell без постоянного изменения политики выполнения.

Реальный Apply — отдельный явный запуск, который может скачивать и устанавливать выбранные программы. Скрипт не устанавливает сам Chocolatey/WinGet, не требует их для твиков, не обновляет существующие приложения автоматически и не инициирует перезагрузку. Поведение сторонних установщиков проверяется отдельно.

## Проверки без установок

```powershell
powershell.exe -NoProfile -File .\tests\Test-Offline.ps1
```

Тестам не нужны Pester, Chocolatey, WinGet и интернет: провайдеры заменяются имитациями в памяти. Проверяются синтаксис, данные каталога и поведение планирования, применения и восстановления. Это проверка логики; она не доказывает совместимость системных изменений с реальной Windows.

## Ограничения

Целевой диапазон — 21H2–26H2. Все сборки пока `Unverified`; preview Apply доступен только для известных x64 Home/Pro из 64-битного процесса и требует явного принятия непроверенного состояния. ARM64, Enterprise, LTSC и другие редакции ждут отдельных тестов.

Автооткат восстанавливает исходные значения реестра. Он не возвращает данные удалённых приложений и не заменяет образ системы. Подробности — в [инструкции по восстановлению](docs/recovery.md).
